# ROV Academy Bot

เว็บแอพ static/PWA แยกจากโปรเจกต์เดิม

## ฟังก์ชันรุ่น 0.1
- เปิด ROV Academy
- กรอกโจทย์และตัวเลือก 2–6 ข้อ
- บันทึกประวัติใน Local Storage
- รองรับติดตั้งเป็น PWA เมื่อเผยแพร่ผ่าน HTTPS

## ข้อจำกัด
ยังไม่มี AI backend หรือฐานความรู้รูน และไม่สามารถอ่าน/ควบคุมแท็บ Garena ข้ามโดเมนได้โดยตรง จึงไม่อ้างว่าสามารถตอบหรือกดคำตอบอัตโนมัติได้ รุ่นถัดไปต้องเชื่อม backend และระบบรับภาพ/ข้อความที่ผู้ใช้อนุญาต
